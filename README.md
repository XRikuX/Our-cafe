# Our-cafe

Описание: 
Our-cafe — это простой веб-сайт для кафе, демонстрирующий базовые навыки верстки и стилизации с использованием HTML и CSS. Этот проект предназначен для начинающих веб-разработчиков, желающих изучить основы создания веб-страниц.

Установка:
1.Клонируйте репозиторий:git clone https://github.com/XRikuX/Our-cafe.git
2.Перейдите в директорию проекта:cd Our-cafe
3.Откройте файл index.html в вашем браузере.

Использование: 
Проект можно использовать для демонстрации основ верстки веб-страниц. Он включает базовую структуру сайта кафе с меню, галереей изображений и контактной информацией.

Зависимости: 
Проект не имеет внешних зависимостей.
